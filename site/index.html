difftab
GitHub npm Changelog

See what your AI coding agent changed — in one browser tab.

A read-only, zero-dependency local viewer for your git working tree: the diff, the file tree and the branch status, refreshing itself while the agent keeps writing. Close the tab and it exits.

Install

Node.js 22+ · macOS · Windows · Linux · zero dependencies

Usage

$ cd /path/to/your/repo
$ difftab
--no-open
Print the URL instead of opening a browser
-v, --version
Print the version and exit
-h, --help
Print help and exit

Nothing to configure: no port to pick, no config file. Running it again in the same repository reuses the open instance.

Why

Your agent finishes a task and you want to see what it actually did. The terminal is not the place to read a 300-line patch — so you open an IDE, not to edit anything, just to read the diff, glance at the tree, check the branch, and close it again.

difftab is that half of the editor without the editor. One command, one tab, and only the three things you actually looked at.

Features

  • + The diff, the way an editor shows it. Staged, unstaged, untracked and conflicting changes, side by side with syntax highlighting. Laid out like VS Code.
  • + The whole repository. Browse the file tree and open any file, not only what changed.
  • + Branch status you can trust. Ahead/behind, no upstream, detached HEAD, a rebase or merge in progress.
  • + Live while the agent writes. The tab refreshes on its own as files change.
  • + Nothing to keep running. Starts instantly, zero dependencies, exits when you close the tab.

Read-only

It never writes to your repository. Only read-only git commands — no stage, commit, discard, pull, push, branch or stash. Enforced by two CI gates on every change, not by promise.

Nothing leaves your machine. The server binds 127.0.0.1. No telemetry, no account, no cloud.

The local page is locked down. A per-session token, Host and Origin checks, and a default-src 'none' CSP. Details

Works with

  • Claude Code
  • Codex
  • OpenCode
  • Aider
  • a human with vim

difftab never talks to the agent — it only reads git. Anything that writes files into a git working tree looks the same to it.

Non-goals

  • −Any repository write operation
  • −Code editing
  • −Accounts and cloud sync
  • −Multi-user review workflows

Deliberately a viewer. Out of scope permanently, not merely unbuilt.
